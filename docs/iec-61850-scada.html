IEC 61850 SCADA in Browser — awtSCADA

awtSCADA is the only SCADA system in the world that supports IEC 61850 (MMS, GOOSE, Sampled Values) and runs entirely in a web browser from a single HTML file.

IEC 61850 Protocol Support

  • MMS (Manufacturing Message Specification) — read/write data from IEDs
  • GOOSE (Generic Object Oriented Substation Event) — fast horizontal communication
  • SV (Sampled Values) — real-time measurement data

Digital Substation Automation

awtSCADA connects to protection relays, bay controllers, and merging units via IEC 61850. Configure SCL files, browse IED data models, and create mimic diagrams — all in your browser.

Free SCADA Software Download — awtSCADA

awtSCADA is a free industrial SCADA system that runs entirely from a single HTML file in any web browser. No installation, no server, no license required for the demo version.

Features

  • 9 industrial protocols: IEC 61850 (MMS, GOOSE, SV), OPC UA, Modbus TCP
  • 53 function blocks for logic, math, PID control
  • 65 graphic elements: pumps, valves, motors, tanks
  • Built-in SQLite database for trends and alarms
  • Python Gateway for real PLC/RTU connections

System Requirements

Any modern web browser (Chrome, Firefox, Edge, Safari). Works on Windows, Linux, macOS.

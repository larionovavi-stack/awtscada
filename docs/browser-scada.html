Browser-Based SCADA — Zero Installation

awtSCADA runs from a single HTML file (~240 KB) in any modern web browser. No Java, no .NET, no server — just open the file and start building your SCADA project.

Why Browser-Based SCADA?

  • Deploy on any device — desktop, tablet, industrial panel
  • No IT infrastructure needed — works offline on air-gapped networks
  • Cross-platform — Windows, Linux, macOS, ChromeOS
  • Instant updates — just replace one HTML file

Supported Protocols

OPC UA, Modbus TCP, IEC 61850 (MMS/GOOSE/SV), OPC DA, MQTT, SNMP, REST API
